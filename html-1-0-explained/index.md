## Origins of HTML 1.0
In late 1991, Tim Berners-Lee published the original 18 tags at CERN in Geneva. HTML 1.0 (RFC 1866) was designed as a lightweight hypertext interchange format for academic researchers.

## Core Elements
- Document shell: `<html>`, `<head>`, `<title>`, `<body>`
- Headings: `<h1>` - `<h6>`
- Text blocks: `<p>`, `<br>`, `<pre>`
- Text emphasis: `<b>`, `<i>`, `<u>`
- Lists: `<ul>`, `<ol>`, `<li>`, `<dl>`, `<dt>`, `<dd>`
- Tables & Links: `<table>`, `<a>`, `<img>`

## Why HTML 1.0 Matters in 2026
1. **Maximum Portability**: Clean code without CSS sheet collisions.
2. **Email Marketing Reliability**: Renders consistently across desktop Outlook, webmail, and mobile clients.
3. **Screen Reader Accessibility**: Zero non-semantic div or span bloat.
4. **Long-Term Archival**: Pure structural documents that never suffer framework obsolescence.
