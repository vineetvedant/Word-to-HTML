## How HTML to Word Conversion Works
Microsoft Word natively supports rendering HTML documents wrapped in a standard MIME structure (`application/msword`) with `.doc` extension:
1. Paste raw HTML code or upload an `.html` file.
2. The engine parses and normalizes the markup, ensuring all tags, tables, headings, and lists are properly structured.
3. The output is previewed in real-time in the interactive preview pane.
4. Clicking 'Download Word' saves a genuine `.doc` file that opens in Microsoft Word, Google Docs, and LibreOffice.

## Supported Elements
- Headings (`<h1>` - `<h6>`)
- Paragraphs & line breaks (`<p>`, `<br>`)
- Bold, italic, underline (`<b>`, `<i>`, `<u>`)
- Bulleted & numbered lists (`<ul>`, `<ol>`, `<li>`)
- Clean tables (`<table>`, `<tr>`, `<td>`, `<th>`)
- Hyperlinks (`<a href="...">`)
