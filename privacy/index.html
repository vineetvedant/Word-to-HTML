Privacy Policy & Security Architecture

Complete transparency on data privacy, client-side processing verification, and how we protect your confidential documents.

By Vedant Singh • Effective October 2026

1. The Core Privacy Principle: Zero Document Uploads

Many online file converters transmit your documents, contracts, and spreadsheets to third-party cloud servers for background rendering. This creates severe compliance risks under GDPR, HIPAA, and corporate confidentiality policies.

Word HTML 1.0 Converter was built with a fundamental architectural constraint: zero server-side document handling.

  • All parsing is executed using the browser's native DOMParser API.
  • Text editing relies on the browser's built-in contenteditable and execCommand APIs.
  • File downloads are created on-the-fly in browser memory using Blob and URL.createObjectURL.
  • At no point are your document contents, pasted text, filenames, or generated HTML code sent across the network.

2. Technical Verification: How to Audit Client-Side Execution

You do not need to take our word for it. You can independently verify our zero-transmission architecture using your browser's Developer Tools:

  1. Press F12 or right-click anywhere on the page and choose Inspect.
  2. Click the Network tab.
  3. Paste sensitive text into the Word Input editor, adjust cleanup toggles, or download a .doc file.
  4. Notice that zero outbound HTTP POST or PUT requests are made. No data packets leave your device.
  5. Disconnect your Wi-Fi or enable Airplane Mode: the converter continues functioning with full fidelity completely offline.

3. Output Security & XSS Prevention

Treating user-pasted markup as untrusted is essential to prevent Cross-Site Scripting (XSS) attacks:

  • Script & Dangerous Tag Purging: Elements like <script>, <iframe>, <object>, and <embed> are removed immediately upon parsing.
  • Protocol Sanitization: Hyperlinks and image sources using javascript:, vbscript:, or non-image data: URIs are automatically stripped.
  • Sandboxed Preview: The live preview rendering uses an <iframe sandbox="allow-same-origin"> container, strictly preventing script execution within the preview context.

4. Local Storage and Cookies

The converter does not set tracking cookies. It uses the browser's local storage solely to remember your user interface preference (such as dark mode vs. light mode via localStorage.getItem("theme")).
